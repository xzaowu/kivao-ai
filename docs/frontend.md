## API 与前端演示的分工

| 行为 | 当前实现 |
| --- | --- |
| 三个核心场景与核心计划所需固定素材查询 | TanStack Query 调用现有 Mock API，并用契约校验响应 |
| 创建／查询核心计划，创建／查询 Mock Creation | 现有 API，错误会显示，不会静默切换成“已成功”的本地计划 |
| 本地文件、补充角色和输出设置 | 前端状态；不上传，不伪造 API Asset ID |
| 向 API 提交素材引用 | 只提交 API 自己返回的 `mock_fixture` 引用；计划页明确说明此边界 |
| 自由图片／视频计划 | 明确标识的前端演示计划，不映射为后端已支持的 Scene |
| 进度、取消、Task、版本、选中调整、审核保存 | 独立前端演示层；不调用不存在的执行、版本或保存 API |
| API 后端 Creation 状态 | 保持真实返回的 `draft`；不把前端完成状态写成后端成功 |
| 作品页 | 人确认的本地作品为主；API 固定演示记录在独立折叠区中列明 |

本轮未修改 API、`packages/contracts` 或 OpenAPI。前端本地会话用独立 ID 关联 Mock Creation；其 Task、Version 与 Work 的契约字段保持引用一致，额外输出、输入快照、场景设置只放在演示适配层。API 估算仍是整数分的模拟人民币金额；计划页同时展示该模拟估算与本次实际演示费用 ¥0，不存在扣费操作。

## 版本与保存规则

确认计划后才开始模拟。运行中输入锁定，可以取消并保留原计划，也可离开页面后从创作列表恢复。取消不会创建半成品 Version。模拟结束一次只新增一个版本。

调整使用当前版本的不可变输入快照，只为选中项更新来源版本号，未选中项保留旧来源；媒体本身仍是预制演示，版本变化不声称真实图像或视频编辑。V1 永不被 V2 覆盖。设置或素材改变后继续展示旧结果，但不能用新设置调整旧结果；可以生成新计划或恢复该版本设置。

人工审核弹窗列出场景检查事项，用户明确点击“我已检查，保存选中项”后才创建本地 Work。Work 固定 Version ID、输出与设置快照；重复保存相同版本、相同输出是幂等的。部分保存的创作仍可以在首页继续。

## 上传、存储与未实现边界

支持 JPG／PNG／WebP 图片和 MP4／WebM 视频。图片最多 10MB、视频最多 50MB，一次最多导入 4 份，本地演示素材最多 30 份。检查类型、大小与文件签名，图片还检查解码；失败显示可恢复提示。Blob URL 只在本页内存保留，不写入持久化记录或 API 请求。

浏览器存储使用独立版本键 `kivao-react-scheme-c-v2`，不读取原型原有键或登录状态。最多保留 100 次会话与 1000 个本地作品。首页目标与有实际输入的工作区草稿也会恢复；空白自由草稿不写入存储。刷新后演示记录、版本和作品可恢复；本地文件明确变成待重选状态，不假装已上传。存储格式损坏时不覆盖原始数据；写入失败时保留当前内存状态并提示风险。

图片与视频的总览、具名工作区和示例详情分开。采用模板后创建独立草稿，其他场景库样本仍只预览。额外工具完全由前端演示层处理：抠图只展示棋盘格示意、不会导出透明 PNG；视频均为 12 秒无声静态运镜预制剪辑，不生成动作、口型或声音，不做真实高清／去字；台词工具返回手写预置稿，按文本展示和下载，不伪装为 ASR 或视频。文本版 Version 类型是前端局部扩展，三个核心场景仍验证现有共享契约；API/OpenAPI 无变更。

画布提供 8 个模板、空白画布、我的画布、改名／复制／最近删除和恢复。节点支持鼠标／触摸拖动、键盘方向键移动、空白平移、缩放与适应视图、便签编辑、图片／视频选择、角色连接与断开、循环拒绝及每个角色替换旧连接。撤销／重做有 25 步上限，运行中禁用。节点任务复用工作区和三核心 Mock API，确认后模拟执行；V1/V2 分别留在画布，审核保存不覆盖版本。画布、Creation 和 Work 各自保留，复制画布会解除原任务引用以建立独立创作。它不是自动执行依赖的通用工作流引擎，不提供协作或真实 AI 节点。

作品／素材区分个人、演示与最近删除，支持搜索、类型／分组筛选、排序、收藏、批量移动与恢复。作品演示样本只有主动保留后才加入我的作品；继续创作建立独立会话。素材重选使用原 ID，因此分组、名称与创作引用保留；文件签名／解码校验仍有效。创作记录支持搜索、状态／类型、排序、改名、置顶、收起／恢复和主动载入标注的演示状态。

整理元数据与画布使用独立存储键，格式损坏不覆盖原记录，配额失败显示提示。所有记录只属于当前浏览器。主题支持浅色、深色和跟随系统；编辑表单误关闭时先保留输入并提示。未引入真实 AI、充值、扣费、生产认证或后台业务。
