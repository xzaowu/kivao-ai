## API 与前端演示的分工

| 行为 | 当前实现 |
| --- | --- |
| 三个核心场景、素材和固定作品记录查询 | TanStack Query 调用现有 Mock API，并用契约校验响应 |
| 创建／查询核心计划，创建／查询 Mock Creation | 现有 API，错误会显示，不会静默切换成“已成功”的本地计划 |
| 本地文件、补充角色和输出设置 | 前端状态；不上传，不伪造 API Asset ID |
| 向 API 提交素材引用 | 只提交 API 自己返回的 `mock_fixture` 引用；计划页明确说明此边界 |
| 自由图片／视频计划 | 明确标识的前端演示计划，不映射为后端已支持的 Scene |
| 进度、取消、Task、版本、选中调整、审核保存 | 独立前端演示层；不调用不存在的执行、版本或保存 API |
| API 后端 Creation 状态 | 保持真实返回的 `draft`；不把前端完成状态写成后端成功 |
| 作品页 | 人确认的本地作品为主；API 固定演示记录在独立折叠区中列明 |

本轮未修改 API、`packages/contracts` 或 OpenAPI。前端本地会话用独立 ID 关联 Mock Creation；其 Task、Version 与 Work 的契约字段保持引用一致，额外输出、输入快照、场景设置只放在演示适配层。API 估算仍是整数分的模拟人民币金额；计划页同时展示该模拟估算与本次实际演示费用 ¥0，不存在扣费操作。

## 版本与保存规则

确认计划后才开始模拟。运行中输入锁定，可以取消并保留原计划，也可离开页面后从创作列表恢复。取消不会创建半成品 Version。模拟结束一次只新增一个版本。

调整使用当前版本的不可变输入快照，只为选中项更新来源版本号，未选中项保留旧来源；媒体本身仍是预制演示，版本变化不声称真实图像或视频编辑。V1 永不被 V2 覆盖。设置或素材改变后继续展示旧结果，但不能用新设置调整旧结果；可以生成新计划或恢复该版本设置。

人工审核弹窗列出场景检查事项，用户明确点击“我已检查，保存选中项”后才创建本地 Work。Work 固定 Version ID、输出与设置快照；重复保存相同版本、相同输出是幂等的。部分保存的创作仍可以在首页继续。

## 上传、存储与未实现边界

支持 JPG／PNG／WebP 图片和 MP4／WebM 视频。图片最多 10MB、视频最多 50MB，一次最多导入 4 份，本地演示素材最多 30 份。检查类型、大小与文件签名，图片还检查解码；失败显示可恢复提示。Blob URL 只在本页内存保留，不写入持久化记录或 API 请求。

浏览器存储使用独立版本键 `kivao-react-scheme-c-v2`，不读取原型原有键或登录状态。最多保留 100 次会话与 1000 个本地作品。自由创作在确认计划前不持久化。刷新后演示记录、版本和作品可恢复；本地文件明确变成待重选状态，不假装已上传。存储格式损坏时不覆盖原始数据；写入失败时保留当前内存状态并提示风险。

画布保留添加演示素材（最多 5 份）、45%–115% 缩放和参考查看；没有拖拽编辑器、AI 节点、布局保存、协作或真实任务执行。积分 0 是展示值，不是账户余额。主题偏好仅本地保存。没有引入真实 AI、充值、扣费、生产身份认证或管理后台业务。
