## 浏览器覆盖

- 1440×900 桌面、390×844 手机，deviceScaleFactor=1。
- 九项导航、桌面侧栏收起/展开、手机侧栏、页面搜索和 Ctrl/⌘ K。
- 浅色、深色、系统主题响应及刷新保留主题。
- 概览 7/30 天趋势、明细、Mock CSV 导出、最近任务定位。
- Model / Provider 分离、搜索、状态和接口过滤、添加/编辑、详情、固定密钥掩码；断言没有业务 API 或演示 Provider 请求。
- 场景分类/状态、分页、预览、编辑及上下架模拟。
- 任务场景/状态筛选、排序、详情时间线、保留原任务的重试、新任务模拟取消。
- 五个业务框架、表单焦点限制、Escape、页签方向键/Home。
- 空、慢速加载、加载错误和恢复；保存错误可见、获得焦点、输入保留和再次保存成功。
- 页面级横向溢出检查；手机表格设计为内部横向滚动，未声称所有列同时可见。

开发过程中的失败/中断运行不计入通过结果。修复了 Admin Tailwind 导入路径、Radix 抽屉/手机侧栏的独立 translate 偏移、手机演示按钮可访问名称、隐式筛选列以及测试定位。最终浏览器测试增加控制台错误检查，避免遗漏无效筛选。
