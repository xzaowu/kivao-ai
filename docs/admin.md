# KIVAO Admin UI

这是第一版可交互管理后台，所有数据与操作均为 **Admin 前端 Mock**。不连接现有业务 API、数据库、AI Provider、支付或身份认证。页面固定显示 Mock 提示，样本均使用演示用户与 `DEMO-` 引用。

界面沿用 KIVAO 蓝白配色与共享 UI，提供浅色、深色和跟随系统主题。这是既有品牌中的管理端扩展，不建立新的品牌或全局设计系统。截图基准为桌面 1440 × 900、手机 390 × 844，见[实际截图及尺寸](admin-screenshots/README.md)。

## 启动和检查

```bash
pnpm install --frozen-lockfile
pnpm dev:admin
# http://127.0.0.1:5174

pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm test:admin
```

浏览器测试会启动或复用本机 Admin，不需要 API 或数据库。首次使用 Playwright 时可执行 `pnpm exec playwright install chromium`。已有兼容浏览器可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/absolute/path/to/chrome pnpm test:admin` 使用。`pnpm --filter @kivao/admin preview` 在 4174 端口预览生产产物；preview 不是生产服务器。部署时需配置 SPA 路由回退。

## 页面与交互

| 页面 | 本轮能力 |
| --- | --- |
| `/` 数据概览 | 5 项 Mock 指标、7/30 天趋势、可聚焦数据点与明细、CSV 导出、模型分布、最近任务、异常摘要、任务定位跳转。当前快照与独立构造的趋势样本明确分开。 |
| `/models` 模型与供应商 | 初始 3 个供应商、4 个模型；独立对象与页签，列表、搜索、状态/供应商/接口过滤、排序、分页、添加、编辑、详情抽屉、启停确认、保存反馈。 |
| `/scenes` 场景管理 | 初始 16 个配置样本，搜索、分类/状态/类型过滤、排序、分页、预览、添加、编辑、上下架模拟。包括基本信息、内置封面、分类标签、素材角色、比例/质量、输出、模型与状态。 |
| `/tasks` 生成任务 | 初始 36 条任务样本，搜索、状态/模型/场景过滤、排序、分页、详情、输入摘要、时间线、成本、错误与结果引用。可模拟重试或取消。 |
| `/users` 用户管理 | 框架：8 个虚构用户资料、搜索和只读详情、接入说明。 |
| `/billing` 积分与计费 | 框架：从同一模型样本读取的定价列表、搜索、配置跳转及计费边界；无积分账本。 |
| `/orders` 订单与充值 | 框架：统一空状态与接入说明；不伪造支付、订单或充值流水。 |
| `/library` 作品与素材 | 框架：作品/素材元数据样本、搜索和详情；无真实文件或内容写入。 |
| `/settings` 系统设置 | 框架：环境、数据源、能力边界和后续安全接入说明；只读。 |

全局包括九项导航、桌面侧栏收起、移动侧栏、面包屑、页面搜索（Ctrl/⌘ K）、浅色/深色/跟随系统主题、键盘焦点、Escape 关闭、未保存修改确认和操作通知。

右上角“演示控制”可复现正常、慢速加载、空数据、加载失败、下次保存失败和重置。保存失败保留编辑内容；失败不会先写入数据。重置需确认。业务数据只存在内存，刷新即恢复初始样本；主题偏好单独保存在本机 localStorage。没有将业务数据、Base URL 或凭据存入本地持久层。

编辑表单的字段区域独立滚动，操作条保持可用；错误摘要位于滚动区域外、操作条上方，并在出错后自动获得焦点。

## 数据和概念边界

- `mock/data.ts`：Zod 配置 Schema、状态文案、独立样本。费用配置单位为元；所有价格、收入和成本均为模拟。
- `mock/adapter.ts`：查询延时、错误模式、纯状态转换、Query/Mutation 钩子。后续真实接入应替换这一边界，而非让组件直接调用 Provider。
- Provider 仅定义连接配置；Model 引用 Provider，定义能力、限制、模拟成本及积分售价。密钥区域是固定的 `•••• •••• DEMO`，无真实输入、解密、显示、连接测试或保存功能。Base URL 只接受不带凭据、查询或片段的 HTTPS 地址，且永不请求。
- Scene 是可复用配置。仅前三个配置记录共享契约的 `product-images` / `virtual-try-on` / `reference-video` 映射；其他记录仅为 Admin 预览。`apiSceneId` 不可编辑，不意味着 API 已支持动态配置 CRUD。
- Creation 是持续创作容器；Task 是一次执行；Version 是不可覆盖结果；Work 是用户保存的版本引用。任务、作品、素材样本采用显式 `DEMO-` ID，**不冒充共享 API 的 UUID 实体，也不作为 API 请求或响应**。本轮无共享契约或 OpenAPI 变更。
- 上架检查模型能力、输入输出上限及启停状态。停用供应商会停用关联模型，并将关联上架场景转为草稿；停用模型同样将关联场景转草稿。涉及关联变更的界面有明确提示。
- 重试失败/取消任务会创建新的排队记录，保留原任务、错误和结果引用；新记录不自动推进或真实执行。仅排队/执行中的演示任务可取消。

## 组件和第三方来源

现有共享 Button / `cn`、TanStack Router 和 Query 保持不变；仅为 Admin 引入所需的 Radix Dialog/Menu、TanStack Table 和 Lucide。图表是由演示数据驱动的 SVG，提供文本明细，不引入图表基础设施。

shadcn-admin 采用选择性复用，参考提交为 `e16c87f213a5ba5e45964e9b67c792105ec74d26`；具体复制、改写与仅参考的文件见[第三方复用记录](third-party/shadcn-admin.md)，并随附[完整 MIT 声明](third-party/shadcn-admin-MIT.txt)。KIVAO 整体许可证尚未决定，本轮没有创建根目录 LICENSE。

## 仍未实现

真实认证、权限控制、审计、管理 API、持久化、动态场景发布、异步任务执行、真实重试/取消、密钥服务、生产指标、积分账本、支付回调、对账、退款、文件审核与存储均未实现。后续接入应先补齐服务端权限与契约，不能将本 UI 的模拟开关视为生产安全措施。
